# 青刻 Android

青刻 Android 由独立开发者维护。本仓库发布 APK、更新清单和版本说明，不包含应用源码。

## 下载

- 当前版本：**1.1.1（内部版本号 1000037）**
- [GitHub Releases 下载](https://github.com/amin180231-creator/qingke-android-updates/releases/latest)
- [GitCode 国内镜像仓库](https://gitcode.com/Maple_One/qingke-android-updates)

最新安装包：`Qingke-Android-v1.1.1-build1000037-release.apk`。

应用启动时会自动检查更新，也可在“版本更新”页手动检查。发现新版本后会显示更新说明并打开对应安装包；安装由 Android 系统确认。

公开仓库只保留最新 APK。覆盖安装使用原正式签名，通常可保留本地数据。版本记录见 [CHANGELOG.md](CHANGELOG.md)。
